# 03｜微积分 I

- 状态：未开始
- 学时预算：35 小时
- 定位：掌握后续机器学习、优化所需的单变量微积分基础。

## 主教材

OpenStax, *Calculus Volume 1*。免费开放教材。\
https://openstax.org/details/books/calculus-volume-1

## 主课程

MIT 18.01SC Single Variable Calculus。\
https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/

## 学习范围

- 函数、图像、复合函数。
- 极限与连续性。
- 导数定义和求导规则。
- 链式法则。
- 极值、变化率和简单优化。
- 定积分与微积分基本定理入门。

## 配套习题

- MIT 18.01SC 早期 Problem Sets。
- 选择 Exam 1、Exam 2 中与已学内容对应的题目。
- 重点练习极限、求导、链式法则、极值与基础积分。

## 实验任务

1. 使用 Python 绘制函数图像。
2. 比较解析导数与数值差分。
3. 使用导数寻找函数极值。
4. 编写简单数值优化程序。
