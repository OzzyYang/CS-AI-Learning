# 04｜数据结构 I

- 状态：未开始
- 学时预算：70 小时
- 定位：建立数据抽象、数据结构实现与复杂度分析能力。

## 主教材

Eric S. Roberts, *Programming Abstractions in C++*。\
Stanford CS106B 课程教材信息：https://web.stanford.edu/class/cs106b/

## 主课程

Stanford CS106B Programming Abstractions。\
https://web.stanford.edu/class/cs106b/

## 学习范围

- ADT、数据抽象、模块化。
- 递归与递归调用栈。
- 单链表、双链表。
- 栈、队列。
- 哈希函数与哈希表。
- 二叉树、二叉搜索树。
- 堆与优先队列。

## 配套习题

从 Stanford CS106B 课程资源中选择：

- ADT 相关练习。
- Recursion 相关练习。
- Linked List 实现练习。
- Priority Queue 相关作业。
- Pathfinder 路径搜索作业。

以课程当前公开版本的作业说明为准，不要求机械完成所有扩展题。

## 实验任务

1. 使用 C++ 实现栈和队列。
2. 独立实现链表及插入、删除。
3. 实现简单哈希表并完成词频统计。
4. 实现二叉搜索树及遍历。
5. 完成 Pathfinder 路径搜索程序。
