# 01｜编程与开发工具

- 状态：未开始
- 学时预算：20 小时
- 定位：能力诊断与工具链补齐，不从零重复学习 C++ 语法。

## 主教材

John V. Guttag, *Introduction to Computation and Programming Using
Python*, 3rd Edition, MIT Press, 2021.\
出版社页面：https://mitpress.mit.edu/9780262542364/introduction-to-computation-and-programming-using-python/

## 主课程

MIT Introduction to Computer Science and Programming in Python。\
课程入口：<https://introcomp.mit.edu/>\
本地镜像（视频 + 讲义 + 代码 + 习题，可直接播放/下载）：[MIT 6.100L 公开课镜像](/公开课/MIT-6.100L/)\
说明：课程版本和作业要求可能更新，开始学习时核对当前页面。

## 学习范围

- Python 数据类型、列表、字典、集合。
- 函数、作用域、面向对象。
- 递归与基本算法。
- 文件读写、CSV、JSON。
- 异常处理、调试、单元测试。
- Git、虚拟环境、命令行。

## 配套习题

- 完成课程基础练习 8–10 道。
- 完成 1 道综合数据处理题。
- 为核心函数编写至少 5 个测试用例。

## 实验任务

1. 批量读取 CSV 并统计数据。
2. 解析 JSON 并转换为另一种结构。
3. 编写命令行数据处理工具。
4. 使用 pytest 编写测试并定位预设错误。
