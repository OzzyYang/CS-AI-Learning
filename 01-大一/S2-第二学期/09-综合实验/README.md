# 09｜综合实验与复习

- 状态：未开始
- 学时预算：20 小时
- 项目名称：CourseSearch｜本地课程资料检索器

## 项目目标

构建一个本地命令行工具，检索指定目录中的 TXT 和 Markdown
课程资料，以综合运用文件处理、数据结构、算法、复杂度分析和软件工程基础。

## 功能要求

- 扫描指定目录中的 TXT、Markdown 文件。
- 提取文本内容。
- 建立关键词索引。
- 支持关键词查询。
- 返回匹配文件和关键词出现次数。
- 输出检索结果。
