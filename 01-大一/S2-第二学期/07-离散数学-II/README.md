# 07｜离散数学 II

- 状态：未开始
- 学时预算：20 小时
- 定位：补足图论、组合计数与递推关系，为算法、网络和 AI 搜索打基础。

## 主教材

Lehman、Leighton、Meyer, *Mathematics for Computer Science*。\
https://courses.csail.mit.edu/6.042/

## 主课程

MIT 6.042J Mathematics for Computer Science。\
https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-fall-2010/

## 学习范围

- 图论基础与连通性。
- 树、路径与图遍历。
- 组合计数。
- 递推关系。
- 模运算。

## 配套习题

选择课程中图论、计数和递推关系相关的精选习题；至少完成 8 道，其中 2
道写出完整证明。

## 实验任务

1. 实现邻接矩阵和邻接表。
2. 编写组合计数验证程序。
3. 编写递推关系计算程序。
