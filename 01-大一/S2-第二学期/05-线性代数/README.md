# 05｜线性代数

- 状态：未开始
- 学时预算：55 小时
- 定位：为机器学习、神经网络、Embedding、降维和优化建立数学基础。

## 主教材

Gilbert Strang, *Introduction to Linear Algebra*, 6th Edition, 2023。\
教材信息：https://math.mit.edu/\~gs/linearalgebra/

## 主课程

MIT 18.06 Linear Algebra。\
https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/

## 学习范围

- 向量与矩阵。
- 矩阵乘法和线性方程组。
- 高斯消元。
- 向量空间与子空间。
- 四个基本子空间。
- 正交、投影和最小二乘。
- 特征值与特征向量。
- 奇异值分解 SVD。

## 配套习题

- MIT 18.06 Problem Sets。
- 选择与已学章节对应的 Exam 1、Exam 2 题目。
- 重点练习线性方程组、子空间、正交投影、特征值和 SVD。

## 实验任务

1. 使用 NumPy 实现矩阵运算。
2. 比较高斯消元与 `numpy.linalg.solve`。
3. 使用最小二乘拟合数据。
4. 使用 SVD 完成简单图像压缩。
