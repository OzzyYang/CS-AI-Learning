# 知识专题

知识专题是**跨课程的知识单元**，用于解决同一个概念在多门课程中重复出现的问题。课程页面负责学习顺序与考核，专题页面负责把概念讲清楚，两者通过关联知识互相引用。

<CatalogGrid type="topics" />

## 专题如何与课程配合

- **课程页**保留培养方案中的顺序、学时、教材与考核要求，不复制专题正文。
- **专题页**围绕一个知识领域组织概念、公式、图表与实验，可在多门课程之间复用。
- 每个专题的 `relatedCourses` 写在 Markdown frontmatter 中，站点会自动生成“关联知识”侧栏。

## 维护约定

新增专题时，在 `知识专题/` 下新建 Markdown 文件，并在 frontmatter 中写明 `title`、`description`、`tag` 与 `relatedCourses`。导航与首页会自动读取，不需要手动登记。
