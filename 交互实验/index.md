# 交互实验

这里收录真正需要“动手操作”的知识点。普通知识仍然使用 Markdown 正文，只有需要状态、输入与即时反馈的内容才封装为独立的 Vue 组件。

<CatalogGrid type="labs" />

## 使用方式

- 先阅读实验上方的说明，再操作组件，最后回到“思考题”检查自己是否理解机制。
- 每个实验都是纯前端组件，不依赖后端服务；构建后同样可以静态部署。
- 组件源码位于 `.vitepress/theme/components/labs/`，每个实验一个文件。

## 设计原则

1. **只为交互而交互**：能用一段代码或一张图讲清楚的内容，不做成组件。
2. **状态可观察**：把内部状态、步骤与结果直接展示出来，而不是只给一个动画。
3. **可重置**：任何实验都可以恢复到确定状态，方便反复尝试。
4. **无副作用**：不写入本地存储、不请求外部接口，刷新即恢复初始状态。

## 扩展方式

新增实验时：

1. 在 `.vitepress/theme/components/labs/` 新建 Vue 组件。
2. 在 `.vitepress/theme/index.ts` 中注册组件。
3. 在 `交互实验/` 新建 Markdown 页面，使用组件标签。
4. 在 frontmatter 中写明 `relatedTopics`，关联知识侧栏会自动生成。
