# 二叉搜索树可视化

二叉搜索树把“有序”编码进结构：左子树全部小于根，右子树全部大于根。这个实验支持插入节点、播放遍历，并实时显示树高与遍历序列。

## 二叉搜索树的性质

对任意节点 $x$：

- 左子树中所有节点的值都小于 $x$。
- 右子树中所有节点的值都大于 $x$。
- 左右子树也分别是二叉搜索树。

因此**中序遍历**会得到一个严格升序序列。这也是判断一棵二叉树是否为 BST 的常用方法：检查中序序列是否单调递增。

## 四种遍历

| 遍历 | 访问顺序 | 典型用途 |
| --- | --- | --- |
| 前序 | 根 → 左 → 右 | 复制树、序列化 |
| 中序 | 左 → 根 → 右 | 得到有序序列 |
| 后序 | 左 → 右 → 根 | 释放树、计算子树信息 |
| 层序 | 按层从左到右 | 求宽度、按层处理 |

## 树高与退化

| 插入顺序 | 树高 | 查找复杂度 |
| --- | --- | --- |
| `50, 30, 70, 20, 40, 60, 80` | 3 | $O(\log n)$ |
| `10, 20, 30, 40, 50` | 5 | $O(n)$ |

当数据已经有序时，普通 BST 会退化成链表。平衡树（AVL、红黑树）通过旋转维持高度为 $O(\log n)$，代价是插入与删除更复杂。

::: tip 随机化与平衡
如果插入顺序近似随机，BST 的期望高度是 $O(\log n)$。但工程中不能依赖输入顺序，因此标准库通常使用平衡树或跳表。
:::
