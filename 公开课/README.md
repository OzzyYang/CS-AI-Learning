# 公开课镜像

这里收录 MIT OpenCourseWare 等公开课的**本地镜像**：官方打包资源（讲义 PDF、课堂代码、习题与解答）已下载到 `public/ocw/`，视频通过官方 YouTube 频道嵌入播放。

新增课程只需一条命令，具体约定见仓库根目录的 `AGENTS.md`：

```bash
npm run ocw:add -- https://ocw.mit.edu/courses/<课程 slug>/
```
